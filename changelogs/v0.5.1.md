# v0.5.1

Date: 2026-04-17

## Added

- Canonical Scene and Milestone temporal model support for ontology instances:
  - Scene and milestone contracts for create/update/read payloads.
  - Scene-level provenance (`derived_from`) anchored to ontology entities.
  - Milestone-level provenance and typed entity relations.
- Scene and milestone API routes for frontend integration:
  - Scene CRUD under `/ontology-instances/{instance_id}/scenes`.
  - Milestone CRUD under `/ontology-instances/{instance_id}/scenes/{scene_id}/milestones`.
- Temporal graph constraints bootstrap for Neo4j on startup:
  - Scene and milestone uniqueness constraints and supporting indexes.
- Validation test coverage focused on scene/milestone temporal constraints.

## Changed

- Ontology instance service now persists and reads scene-centric temporal data as canonical write flow.
- Ontology instance read payloads include scenes and nested milestones.
- Legacy Event write endpoints are now blocked (deprecation conflict behavior), while read compatibility remains available.

## Notes

- This release introduces the scene-centric temporal baseline while preserving compatibility for legacy event reads.
- Public runtime/API version is now `0.5.1`.
