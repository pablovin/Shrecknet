# v0.5.3

Date: 2026-04-17

## Added

- Additive retrieval API fields for GraphRAG semantic search and Elder retrieval responses:
  - Request controls: `node_scope`, `candidate_limit`, `rerank_limit`
  - Per-result scoring telemetry: `chunk_score`, `node_score`, `importance_index`, `matched_chunk_count`, `score_breakdown`
  - Graph-aware enrichments: `graph_boost`, `evidence_bundle`
  - Top-level GraphRAG response aggregation: `evidence_bundles`

## Notes

- These fields are additive and backward-compatible: existing request/response fields remain valid and unchanged.
- Public runtime/API version remains `0.5.2`.
