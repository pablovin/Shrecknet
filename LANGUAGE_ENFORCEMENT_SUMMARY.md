# Language Enforcement in Architect Generation Pipeline

## Problem Statement
The `architect.generate_entities` job in `backend_v2` was generating all text content in English, even when the original input was in other languages (Portuguese, Spanish, etc.). While a language detection function existed (`_detect_language` and `_collect_original_text`), the language context wasn't consistently enforced throughout the entire pipeline, particularly in:

- Autogenerated entity summaries
- Timeline event descriptions
- Property values
- Relationship justifications

## Solution Overview
We strengthened language enforcement across all text generation points in the v2 pipeline by:

1. **Expanding language support** - Added 30+ common languages
2. **Improving language detection** - Better fallback for unknown languages
3. **Strengthening all LLM prompts** - Made language requirement CRITICAL and non-negotiable
4. **Enhancing JSON examples** - Show language requirement in all fields
5. **Improving logging** - Track detected language for debugging

## Detailed Changes

### 2. Improved Language Detection
**Before:**
```python
return detected_code, _LANGUAGE_LABELS.get(detected_code, "the original language")
```

**After:**
```python
language_name = _LANGUAGE_LABELS.get(
    detected_code, 
    f"{detected_code.upper()} (detected language)"
)
return detected_code, language_name
```

Now instead of generic "the original language", unknown languages get specific labels like "FI (detected language)" for Finnish.

### 3. Strengthened LLM Prompts

#### Chunk Extraction Prompt
**Before:**
```python
"All generated text (properties, relationships, summaries, timeline events) must be in {language_name}."
```

**After:**
```python
f"CRITICAL: You MUST write ALL generated text in {language_name}. This is NON-NEGOTIABLE.",
"You are the Architect Agent. Read the CHUNK and extract data for each TARGET.",
# ... other instructions ...
f"REMINDER: All text in properties, relationships justifications, summaries, and timeline events MUST be in {language_name}.",
```

#### System Message for Extraction
**Before:**
```python
"You are an information extraction specialist. Return only the requested JSON "
f"and ensure every piece of generated text is written in {language_name}."
```

**After:**
```python
f"You are an information extraction specialist working in {language_name}. "
f"CRITICAL REQUIREMENT: Every piece of generated text MUST be written in {language_name}. "
"Return only the requested JSON format."
```

#### Summary Synthesis
**Before:**
```python
"You refine encyclopedia entries. Combine an existing summary with new findings, "
"emphasizing what changed. Return 2-3 concise sentences without repeating ideas verbatim. "
f"Always respond in {language_name}."
```

**After:**
```python
f"You are an encyclopedia editor working exclusively in {language_name}. "
f"CRITICAL: ALL your responses MUST be in {language_name}. "
"Combine an existing summary with new findings, emphasizing what changed. "
"Return 2-3 concise sentences without repeating ideas verbatim."
```

#### HTML Formatting
**After:**
```python
f"You are an HTML formatter working exclusively in {language_name}. "
f"CRITICAL: You MUST preserve the exact language of the input text ({language_name}). "
"If text is long or contains multiple themes, rewrite it as concise HTML with headings and paragraphs. "
"Keep tone neutral. DO NOT translate or change the language."
```

### 4. Enhanced JSON Schema Examples

**Before:**
```json
{
  "properties": [{"definition_id": 123, "value": "text"}],
  "relationships": [{"justification": "why this alias fits the required target type"}],
  "summary": "2-3 sentence summary for this entity based on this chunk",
  "timeline_events": [
    {
      "title": "succinct event title",
      "description": "what happened and why it matters"
    }
  ]
}
```

**After:**
```json
Return JSON array (ALL text values MUST be in Portuguese):
[
  {
    "properties": [{"definition_id": 123, "value": "text in Portuguese"}],
    "relationships": [{"justification": "justification in Portuguese"}],
    "summary": "2-3 sentence summary in Portuguese",
    "timeline_events": [
      {
        "title": "event title in Portuguese",
        "description": "description in Portuguese"
      }
    ]
  }
]

Rules:
- ALL TEXT MUST BE IN Portuguese - this includes property values, relationship justifications, summaries, timeline titles and descriptions.
```

Added proper logging for language detection:

logger.info(

## Usage Example

When a user submits text in Portuguese:
```
"Jessie é uma personagem importante na história..."
```

The system will:
1. Detect language: `"pt"` → `"Portuguese"`
2. Pass `language_name="Portuguese"` to all LLM calls
3. Generate all text in Portuguese:
   - Properties: `"idade": "30 anos"`
   - Relationships: `"justification": "Jessie é mencionada como amiga de..."`
   - Summary: `"Jessie é uma personagem central que..."`
   - Timeline: `"title": "Encontro com Baron Jackie"`
