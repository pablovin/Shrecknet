# v0.5.0

Date: 2026-04-17

## Added

- Split-domain foundations for standalone RPG handling under `shreckrpg`:
  - Dedicated RPG-side persistence and endpoint surface for games, sessions, notes, notifications, and related user activity.
  - Compatibility-focused route support for nested game/session paths and migration orchestration.
- Legacy old-db import capabilities expanded:
  - Import support for older schema variants (including tables without expected synthetic IDs).
  - Preservation of legacy game metadata (including calendar/VTT fields and aliases).
  - Expanded migration of page-visits/favorites with safer fallback behavior for optional legacy columns.

## Changed

- Decoupled RPG responsibilities from core Shrecknet graph maintenance flows to reduce coupling between world graph and campaign runtime concerns.
- Hardened cross-service import orchestration between Shrecknet and ShreckRPG:
  - Transient `/jobs/{id}` polling failures (for example startup-time `503`) now retried.
  - Import paths account for stale engine/session state after SQLite replacement.
- Improved deployment/runtime resilience for split compose stacks:
  - Better handling of bind-mount ownership/permission drift after manual cleanup.
  - More predictable startup behavior for API/worker pairs using shared mounted storage.
- Continued modernization of agent pipelines and supporting modules in `shrecknet/app`:
  - Expanded Architect/Elder/Librarian/Novelist orchestration surfaces.
  - Retrieval/chunking/refinement improvements tied to graph and document QA workflows.

## Notes

- This release consolidates the split-era changes delivered after `v0.3.0` into a single baseline version for coordinated deployment.
- Public runtime/API version is now `0.5.0`.
