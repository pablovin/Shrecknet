# Scene-Centric Embedding

This document describes how embeddings work now and the three endpoints the frontend should use.

## Embedding Model Overview

Shrecknet embeds graph memory into `EntityChunk` vectors for retrieval.

- Embedded types: `EntityInstance`, `Scene`, `Milestone`

Chunk content includes:

- Entity context: text/autogenerated text, properties, and structural links
- Scene context: scene description plus ordered milestone structure
- Milestone context: milestone properties and related entities

Embeddings are refreshed when nodes are unembedded or outdated.

## 1) GET /ontologies/{ontology_id}/embedding-stats

Returns aggregate and per-type embedding counters.

Request:

```http
GET /ontologies/12/embedding-stats
Authorization: Bearer <token>
```

Response:

```json

	"total_nodes": 132,
	"embedded_nodes": 127,
```

## 2) POST /ontologies/{ontology_id}/trigger-embedding

Starts a background embedding job.

Request:

```http
POST /ontologies/12/trigger-embedding
Authorization: Bearer <token>
Content-Type: application/json

{}
```

Response:

```json
{
	"job_id": "d1c1c2d3-6d7e-4e59-9d9a-0f1a2b3c4d5e",
	"ontology_id": 12,
	"message": "Embedding job triggered for ontology 12",
	"requested_entities": 100,
	"requested_scenes": 20,
	"requested_milestones": 12
}
```

## 3) GET /ontologies/{ontology_id}/embedding-jobs?limit=10

Returns recent embedding jobs for polling UI status.

Request:

```http
GET /ontologies/12/embedding-jobs?limit=10
Authorization: Bearer <token>
```
