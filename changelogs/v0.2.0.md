# v0.2.0

Date: 2026-04-11

## Added

- Full system backup package pipeline:
  - SQLite dataset snapshot from configured data directory.
  - Neo4j logical export (`graph.json` + `schema.json`).
  - Full media backup excluding `media/backups/**`.
- Structured backup storage:
  - `media/backups/download/` for generated archives.
  - `media/backups/upload/` for uploaded restore archives.
- Backup archive manifest with checksums (`manifest.json`).
- Path traversal-safe tar extraction validation.
- Maintenance mode service for destructive restore windows.
- New runtime version source at `backend/app/core/version.py`.

## Changed

- Backup and restore jobs now report richer phases through `/jobs` details:
  - `staging`, `sqlite_copy`, `neo4j_dump`, `media_copy`, `manifest`, `archive`,
  - `validating`, `sqlite_restore`, `media_restore`, `neo4j_import`, `finalizing`.
- Health endpoint now exposes version:
  - `GET /health` returns `status`, `service`, and `version`.
- Package version bumped to `0.2.0` in `backend/pyproject.toml`.

## Notes

- Public backup API routes remain unchanged (`/backups/create`, `/backups/restore`, `/backups/`, `/backups/{filename}/download`).
- Restore remains destructive and is intended for a short maintenance window.
