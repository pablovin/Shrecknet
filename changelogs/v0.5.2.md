# v0.5.2

Date: 2026-04-17

## Added

- Focused embedding endpoint documentation with request/response examples for:
  - `GET /ontologies/{ontology_id}/embedding-stats`
  - `POST /ontologies/{ontology_id}/trigger-embedding`
  - `GET /ontologies/{ontology_id}/embedding-jobs?limit=10`
- Updated embedding frontend reference docs under `Documentation/SceneCentricMemory/Embedding` aligned with current API shape.

## Changed

- Removed Event nodes from active embedding flow:
  - Ontology embedding now processes only `EntityInstance`, `Scene`, and `Milestone`.
  - Retrieval filtering excludes Event-backed embedding parents.
- Updated ontology embedding API responses to remove Event counters:
  - Embedding stats now return typed breakdowns for `entities`, `scenes`, and `milestones`.
  - Trigger embedding response now returns `requested_entities`, `requested_scenes`, and `requested_milestones`.
- Reduced Neo4j warning noise in scene read/update/delete flows by replacing explicit `HAS_SCENE`/`Scene` pattern matches in query paths with runtime type/label guards where appropriate.

## Fixed

- Suppressed repeated Neo4j `UnknownRelationshipTypeWarning` and `UnknownLabelWarning` messages when scene labels/relationships are absent in sparse graph states during ontology-instance scene lookups.

## Notes

- Public runtime/API version is now `0.5.2`.
- Existing timeline Event read compatibility remains available, but Event nodes are no longer part of embedding processing or embedding stats/trigger counters.
